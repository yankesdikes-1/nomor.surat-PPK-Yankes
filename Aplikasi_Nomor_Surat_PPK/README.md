# Aplikasi Pengambilan Nomor Surat PPK

Aplikasi web modern untuk pengambilan dan pengelolaan nomor surat resmi PPK (Pusat Pelayanan Kesehatan / instansi terkait) dengan format otomatis dan fitur lengkap.

## Fitur Utama:
1. **Format Penomoran Otomatis**: Menghasilkan nomor dengan format `[Nomor]/[Bulan Romawi]/PPK/[Bagian]/[Tahun]` (Contoh: `19.20/I/PPK/YANKES/2026`).
2. **Pilihan Tanggal Surat**: Mendukung pengambilan nomor untuk hari ini maupun tanggal yang sudah lewat.
3. **Format Sub-Urutan Otomatis**: Jika terdapat pengambilan nomor di tanggal yang sama, format otomatis menjadi `1.1`, `1.2`, dan seterusnya.
4. **Nuansa Biru Profesional**: Antarmuka bersih, responsif, dan elegan menggunakan Tailwind CSS.
5. **Pencatatan Lengkap & Riwayat**: Menyimpan perihal, nama pemohon, bagian unit, serta tombol salin nomor sekali klik (`clipboard`).
6. **Penyimpanan Lokal (LocalStorage)**: Data tersimpan aman di browser Anda.

## Cara Menjalankan:
1. Ekstrak file ZIP ini.
2. Buka file `index.html` menggunakan browser web apa saja (Chrome, Firefox, Edge, Safari).
3. Aplikasi siap digunakan!
